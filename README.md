# Tiletopia — Play Now

**Play now: https://elchinjabbarli.github.io/tiletopia/**

(Tap matching fruit tiles into the tray; collect three of a kind to clear them.
Journey through hand-crafted, always-solvable levels with Koko the parrot.)

- 60 levels (progressively harder, every level pre-validated as solvable)
- TR / EN, auto-detected from your device language
- Works fully offline (installable PWA) — zero network requests
- No accounts, no analytics, no tracking; progress stays on your device
- Boosters: undo, shuffle, hint, +tray slot
- Demo ads simulate rewarded/interstitial flows (no real ad SDK on the web)

Offline: open `index.html` directly, or serve this directory with any static
server. The site also installs as a PWA (add to home screen).

Built with TypeScript + Canvas + WebAudio. All art, sound and code original.

Version: 1.0.0
